# UI FoodHub — Restaurant Ordering and Inventory System

## Project Overview

**UI FoodHub** is a web-based Restaurant Ordering and Inventory Management System developed as a semester project for the Department of Computer Science, University of Ibadan.

The system uses **Tedder Restaurant, University of Ibadan**, as the case study. It is designed to improve the process of ordering meals, tracking customer orders, managing restaurant inventory, and supporting cafeteria staff in their daily operations.

## Key Features

### Customer Features

- Browse available meals
- Search and filter meals by category
- Add meals to cart
- Increase or decrease item quantities
- View cart and order total
- Complete checkout with customer information
- Select collection or delivery
- Select a payment method
- Receive order confirmation
- Track order status

### Staff Features

- Staff login portal
- View customer orders
- View order details
- Update order status
- Manage inventory
- Update stock quantities
- View inventory stock levels
- View meal recipes and ingredients

## Order Workflow

The customer ordering process follows this workflow:

**Browse Menu → Add to Cart → Checkout → Place Order → Order Confirmation → Order Tracking → Collection/Delivery**

## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/TERRYKRIZZ/UI-FoodHub.git
```

### 2. Navigate to the frontend folder

```bash
cd UI-FoodHub/frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
