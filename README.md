# 🍽️ UI-FoodHub

### Restaurant Ordering and Inventory Management System

UI-FoodHub is a web application project designed around restaurant ordering and inventory management. It was developed as a practical project associated with Tedder Restaurant, University of Ibadan.

🔗 **Live Demo:** [ui-food-hub.vercel.app](https://ui-food-hub.vercel.app)

## 📌 About the Project

UI-FoodHub explores how a digital platform can support restaurant operations through an organised interface for ordering and inventory-related workflows.

## ✨ Project Highlights

- Restaurant-focused web application
- User interface for restaurant-related workflows
- Ordering and inventory management project concept
- Deployed live demo for exploring the application

*The exact functionality available in the live demo may differ from these project goals.*

## 🛠️ Technologies

- JavaScript
- CSS
- React and Vite, used in the frontend project

This project demonstrates practical work on a restaurant-focused web application, with an emphasis on interface development and digital solutions for everyday business workflows.
